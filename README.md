## Introduction
This project aims to analyse cancer patient waiting times across NHS Scotland by evaluating the performance of each health board and cancer type category. 
The data is collected to monitor compliance with the cancer waiting time standards set out in the Scottish Government. 
It provides data-driven insights through visualisations and offers actionable solutions based on the findings.

The dataset used in this project was obtained from the Public Health Scotland website, a reputable and reliable source that ensures the authenticity and credibility of the data.
The dataset comprises 8 columns and approximately 40,800 rows.
